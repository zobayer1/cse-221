Toolbox from the lecture
f = O(g)there are constants c, n0 > 0 with 0 ≤ f(n) ≤ c · g(n) for all n ≥ n0 (like ≤)
f = Ω(g)there are constants c, n0 > 0 with 0 ≤ c · g(n) ≤ f(n) for all n ≥ n0 (like ≥)
f = Θ(g)both at once: c1 · g(n) ≤ f(n) ≤ c2 · g(n) for all n ≥ n0 (like =)
f = o(g), ω(g)strict versions (like < and >): the inequality must hold for every constant c > 0

AProve it with the definitions

Find the constants, or show that no constants can work.

  1. Show that 3n + 7 = O(n).
    For n ≥ 1, 7 ≤ 7n, so 3n + 7 ≤ 10n: c = 10, n0 = 1. (Also c = 4, n0 = 7, since 7 ≤ n from n = 7 on.)
  2. Show that 20n2 + 2n + 5 = O(n2) using c = 21. What is the smallest n0 that works with this c?
    We need n2 ≥ 2n + 5. At n = 3: 9 < 11 fails. At n = 4: 16 ≥ 13 holds, and n2 grows faster than 2n + 5 from there on. Smallest n0 = 4.
  3. Show that 1000n2 + 1000n = O(n2). Give two different pairs (c, n0) that work.
    c = 2000, n0 = 1, since 1000n ≤ 1000n2 for n ≥ 1. Or c = 1001, n0 = 1000, since 1000n ≤ n2 exactly when n ≥ 1000. (c = 1001 with n0 = 1 fails: at n = 1, 2000 > 1001.)
  4. Show that 2n2 − 7n + 3 = Ω(n2).
    For n ≥ 7, 7n ≤ n2, so 2n2 − 7n + 3 ≥ 2n2 − n2 + 3 ≥ n2: c = 1, n0 = 7. (Also 2n2 − 7n + 3 ≥ 0 from n = 3 on, as the definition needs.)
  5. Show that 20n3 + 7n + 1000 = Θ(n3).
    Floor: dropping the positive terms, ≥ 20n3 for n ≥ 1. Ceiling: for n ≥ 1, 7n ≤ 7n3 and 1000 ≤ 1000n3, so ≤ 1027n3. c1 = 20, c2 = 1027, n0 = 1. (A tighter ceiling: c2 = 21 works from n0 = 11, not 10: at n = 10, 1000 < 1070.)
  6. Show that 2n + n2 = O(2n).
    n2 ≤ 2n for every n ≥ 4 (16 = 16 at n = 4; after that 2n doubles while n2 grows by a factor of at most 25/16 < 2). So 2n + n2 ≤ 2 · 2n: c = 2, n0 = 4. (At n = 3: 17 > 16.)
  7. Show that n3 ≠ O(n2).
    Suppose n3 ≤ c · n2 for all n ≥ n0. Dividing by n2: n ≤ c for all n ≥ n0. This fails at n = max(n0, ⌈c⌉ + 1). So no pair works.
  8. Show that n ≠ Ω(n log n).
    Suppose n ≥ c · n log n for all n ≥ n0. Dividing by n: log n ≤ 1/c, which fails once n > 21/c. So no pair works.
  9. Is 2n + 1 = O(2n)? Is 22n = O(2n)? Prove both answers. (CLRS Exercise 3.1-4)
    Yes: 2n + 1 = 2 · 2n, so c = 2, n0 = 1. No: 22n ≤ c · 2n means 2n ≤ c, which fails once n > log2 c.
  10. For functions f, g ≥ 0, prove that max(f(n), g(n)) = Θ(f(n) + g(n)). (CLRS Exercise 3.1-1) Challenge
    The larger of two non-negative numbers is at least half their sum and at most the sum: ½(f + g) ≤ max(f, g) ≤ f + g. So c1 = 1/2, c2 = 1, n0 = 1.

COrder by growth

List these from slowest-growing to fastest-growing. Put functions that are Θ of each other in the same group.

n2, 2n, n log n, log2 n, √n, n!, 100, n3, log2(n2), 3n + 5, n1.5, 2n + 1, log10 n

100  ≺  { log2 n, log10 n, log2(n2) }  ≺  √n  ≺  3n + 5  ≺  n log n  ≺  n1.5  ≺  n2  ≺  n3  ≺  { 2n, 2n + 1 }  ≺  n!. The three logs differ only by constant factors; 2n + 1 = 2 · 2n.

DSimplify

Give the simplest g(n) with f(n) = Θ(g(n)), using the rules from the lecture.

  1. 5n3 + 2n2 log n + 1000
    Θ(n3): the sum keeps its largest term.
  2. (n + 3)(n log n + 1)
    Θ(n2 log n): Θ(n) · Θ(n log n).
  3. log(n3) + log(5n)
    Θ(log n): 3 log n + log 5 + log n.
  4. 3n + n100
    Θ(3n): any exponential beats any polynomial.
  5. (n2 + n) / (n + 1)
    Θ(n): it equals n(n + 1)/(n + 1) = n.
  6. 4log2 n
    Θ(n2): 4log2 n = (2log2 n)2 = n2.
  7. n2/log n + n√n
    Θ(n2/log n): their ratio is √n/log n, which grows.
  8. m2 + n log n (two input sizes m and n)
    Θ(m2 + n log n): neither term can be dropped without knowing how m and n compare.

EAnalyze the loops

Give a Θ bound on the running time of each procedure, in terms of n. Every simple step takes Θ(1). Arrays are 0-indexed, as in the slides.

1. TWO-LOOPS 
1TWO-LOOPS(n)
2    s = 0
3    for i = 0 to n − 1
4        s = s + i
5    for j = 0 to n − 1
6        s = s + 2 · j
7    return s
Θ(n): two loops one after another, n + n iterations.
2. NESTED 
1NESTED(n)
2    count = 0
3    for i = 0 to n − 1
4        for j = 0 to n − 1
5            count = count + 1
6    return count
Θ(n2): n · n iterations.
3. UPPER-TRIANGLE 
1UPPER-TRIANGLE(n)
2    count = 0
3    for i = 0 to n − 1
4        for j = i to n − 1
5            count = count + 1
6    return count
Θ(n2): n + (n − 1) + … + 1 = n(n + 1)/2.
4. TRIANGLE-THEN-FILL 
1TRIANGLE-THEN-FILL(A, n)
2    count = 0
3    for j = 0 to n − 1
4        for i = 0 to j
5            count = count + 1
6    for k = 0 to n − 1
7        A[k] = k
8    return count
Θ(n2): n(n + 1)/2 + n; the sum keeps the larger part.
5. HALVING 
1HALVING(n)
2    count = 0
3    k = n
4    while k ≥ 1
5        count = count + 1
6        k = ⌊k / 2⌋
7    return count
Θ(log n): k halves each time, so ⌊log2 n⌋ + 1 iterations.
6. LOG-INSIDE 
1LOG-INSIDE(n)
2    count = 0
3    for i = 0 to n − 1
4        k = 1
5        while k < n
6            k = 2 · k
7            count = count + 1
8    return count
Θ(n log n): each of the n outer iterations runs the inner loop ⌈log2 n⌉ times.
7. HALVING-INNER 
1HALVING-INNER(n)
2    count = 0
3    k = n
4    while k ≥ 1
5        for j = 0 to k − 1
6            count = count + 1
7        k = ⌊k / 2⌋
8    return count
Θ(n): n + n/2 + n/4 + … is between n and 2n (a geometric series), not n log n.
8. SQUARE-ROOT 
1SQUARE-ROOT(n)
2    count = 0
3    i = 1
4    while i · i ≤ n
5        i = i + 1
6        count = count + 1
7    return count
Θ(√n): the loop stops once i > √n, after ⌊√n⌋ iterations.
9. THREE-LEVELS 
1THREE-LEVELS(n)
2    count = 0
3    for i = 0 to n − 1
4        for j = 0 to i
5            for k = 0 to j
6                count = count + 1
7    return count
Θ(n3): the count is n(n + 1)(n + 2)/6, about n3/6.
10. BRANCH · Give the best case and the worst case.
1BRANCH(A, n)
2    if A[0] == 0
3        return 0
4    s = 0
5    for i = 0 to n − 1
6        s = s + A[i]
7    return s
Best case Θ(1) (A[0] = 0); worst case Θ(n). On every input the time is O(n) and Ω(1).
11. HAS-DUPLICATE · Give the best case and the worst case.
1HAS-DUPLICATE(A, n)
2    for i = 0 to n − 1
3        for j = i + 1 to n − 1
4            if A[i] == A[j]
5                return TRUE
6    return FALSE
Best case Θ(1) (A[0] == A[1]); worst case Θ(n2) (no duplicates: n(n − 1)/2 comparisons).
12. HALVE-EACH · Challenge
1HALVE-EACH(n)
2    count = 0
3    for i = 1 to n
4        j = i
5        while j > 1
6            j = ⌊j / 2⌋
7            count = count + 1
8    return count
Θ(n log n): the inner loop runs ⌊log2 i⌋ times. That is at most log2 n for every i, and at least log2 n − 2 for each of the n/2 largest i.
