Strict bounds: little-o and little-omega
Strict bounds
o(g(n)), little-o: f grows strictly slower
for every c > 0 there is an n0 with 0 ≤ f(n) < c · g(n) for all n ≥ n0
Example: 2n = o(n2), but 2n2 ≠ o(n2) (CLRS, p. 50).
ω(g(n)), little-omega: f grows strictly faster
for every c > 0 there is an n0 with 0 ≤ c · g(n) < f(n) for all n ≥ n0
Example: n2/2 = ω(n), but n2/2 ≠ ω(n2) (CLRS, p. 51).

The difference: for O, some c must work. For o, every c must work, however small.
