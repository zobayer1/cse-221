Answer: n2 is not O(n)
Suppose some pair works
1Then n2 ≤ c · n for all n ≥ n0.
2Divide both sides by n: n ≤ c for all n ≥ n0.
3But n = max(n0, ⌈c⌉ + 1) is at least n0 and bigger than c. Contradiction.
n2 ≠ O(n)
No constant c can hold back a factor that keeps growing: n2 passes c · n at n = c, whatever c is. To show f ≠ O(g), show that every pair (c, n0) fails.
