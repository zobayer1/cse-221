2    count = 0

4        for j = 0 to i

Count the runs
For each i, the inner loop runs i + 1 times.
Total: 1 + 2 + … + n = n(n + 1)/2
About half the n × n square, and half is only a constant factor.

COUNT-A is Θ(n2)

The arithmetic series, CLRS (A.1), p. 1146.
