Big-Theta: the definition

f(n) = Θ(g(n)) means f grows exactly like g, up to constant factors.Read it as “f is big-Theta of g”.

Definition (CLRS, p. 44)
Θ(g(n)) = { f(n) : there exist positive constants c1, c2 and n0 such that 0 ≤ c1 · g(n) ≤ f(n) ≤ c2 · g(n) for all n ≥ n0 }
Theorem 3.1 (CLRS, p. 48)
f(n) = Θ(g(n)) if and only if f(n) = O(g(n)) and f(n) = Ω(g(n)). To prove Θ, prove O and Ω, then take the larger n0.
