Asymptotic arithmetic (1)
1Constant factors drop
k · f(n) = Θ(f(n)) for any constant k > 0
e.g. 100n2 = Θ(n2), (log n)/2 = Θ(log n)
2A sum keeps its largest term
f(n) + g(n) = Θ(max(f(n), g(n)))
because max ≤ f + g ≤ 2 · max. e.g. n2 + n log n = Θ(n2)
3A polynomial is its top power
ad nd + … + a1n + a0 = Θ(nd) when ad > 0
e.g. 3n3 − 100n2 + 7 = Θ(n3) (CLRS, p. 46)
Two input sizes? Keep both
Reading an array of size m and then one of size n takes Θ(m + n). Writing just Θ(n) is only right if we know m = O(n).
