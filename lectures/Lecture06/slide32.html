Analyzing loops: the rules
The rules
Simple stepAn assignment, comparison or arithmetic step: Θ(1).
One after anotherAdd the costs, so the largest one wins.
if / elseThe test, plus the more expensive branch (worst case).
A loop(number of iterations) × (cost of one iteration).
Nested loopsWork from the inside out.
1EXAMPLE(A, n)
2    s = 0                         Θ(1)
3    for i = 0 to n − 1           n times
4        if A[i] > 0              Θ(1)
5            s = s + A[i]          Θ(1)
6    for i = 0 to n − 1           n times
7        for j = 0 to n − 1       n times each
8            s = s + 1             Θ(1)
9    return s                      Θ(1)
