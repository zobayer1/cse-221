Proving Big-Theta

Is 2n2 + 3n + 5 = Θ(n2)?

Floor: the Ω part
2n2 ≤ 2n2 + 3n + 5
Dropping the positive terms 3n + 5 makes it smaller. True for every n ≥ 1, so c1 = 2.
Ceiling: the O part
2n2 + 3n + 5 ≤ 10n2
Already proved on the Big-O slides, for every n ≥ 1, so c2 = 10.
c1 = 2, c2 = 10, n0 = 1 work, so 2n2 + 3n + 5 = Θ(n2).
One half is not enough

n = O(n2), but n is not Ω(n2). So n is not Θ(n2).

In the textbook

CLRS proves ½n2 − 3n = Θ(n2) with c1 = 1/14, c2 = 1/2, n0 = 7 (p. 46).
