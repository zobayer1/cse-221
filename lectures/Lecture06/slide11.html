Big-O: the definition

f(n) = O(g(n)) means f grows no faster than g, up to a constant factor.Read it as “f is big-O of g”.

Definition (CLRS, p. 47)
O(g(n)) = { f(n) : there exist positive constants c and n0 such that 0 ≤ f(n) ≤ c · g(n) for all n ≥ n0 }

O(g(n)) is a set of functions. Writing f(n) = O(g(n)) really means f(n) ∈ O(g(n)): here “=” is read “is”, not “equals”.
