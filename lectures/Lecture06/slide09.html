Both knobs together (1)
f(n)The function we want to describeUsually a running time we counted, like 3n + 10.
g(n)A simple function to compare it withLike n, n2 or log n: one term, no constants.
The condition

f(n) grows no faster than g(n) if we can pick a multiplier c and a starting point n0 so that

f(n) ≤ c · g(n) for every n ≥ n0

In the picture: f(n) = 3n + 10 is black, c · g(n) = 4n is red, and n0 = 10. Nothing is compared before n0. From n0 on, the red line never drops below the black one.
