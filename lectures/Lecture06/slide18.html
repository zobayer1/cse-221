Big-Omega: the definition

f(n) = Ω(g(n)) means f grows at least as fast as g, up to a constant factor.Read it as “f is big-Omega of g”.

Definition (CLRS, p. 48)
Ω(g(n)) = { f(n) : there exist positive constants c and n0 such that 0 ≤ c · g(n) ≤ f(n) for all n ≥ n0 }
O
0 ≤ f(n) ≤ c · g(n)
upper bound: f stays on or below c · g
Ω
0 ≤ c · g(n) ≤ f(n)
lower bound: f stays on or above c · g

Everything else is the same: one c, one n0, for all n ≥ n0. So f(n) = Ω(g(n)) exactly when g(n) = O(f(n)) (CLRS, p. 52).
