Logs and exponents
Logarithms

The base does not matter

loga n = logb n / logb achanging the base only divides by a constant (CLRS eq. 3.15, p. 56)
log2 n = Θ(log10 n) = Θ(log n)so we just write log n, as in Lecture 2
log(nk) = k log n = Θ(log n)a power inside the log is a constant factor outside it
Exponentials

The base does matter

3n / 2n = 1.5n grows without boundso 2n = o(3n): 2n and 3n are not Θ of each other
2n + 1 = 2 · 2n = Θ(2n)a +1 in the exponent is a constant factor
22n = 4n ≠ O(2n)a factor in the exponent changes the base: 4n / 2n = 2n grows
