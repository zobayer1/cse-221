Reminder: a straight line

f(n) = 3n + 10

3Slope: f grows by 3 for each extra input.10Intercept: the value at n = 0, a head start.

In school you wrote y = mx + c. Here c already names the multiplier knob, so we write a straight line as a · n + b: slope a, intercept b.

Slope ↔ the multiplier

The knob c makes c · n, a line from 0 with slope c. To ever catch up with 3n + 10, it must be steeper: c > 3.

Head start ↔ the starting point

The head start of 10 is why we need the knob n0. A steeper c · n catches up at n = 10 / (c − 3).
