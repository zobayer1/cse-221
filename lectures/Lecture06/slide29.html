Asymptotic arithmetic (2)
4Products multiply
f1 = O(g1) and f2 = O(g2) give f1 · f2 = O(g1 · g2)
The same holds for Θ. e.g. n iterations of Θ(log n) work each: n · Θ(log n) = Θ(n log n)
5Bounds chain
f = O(g) and g = O(h) give f = O(h)
Also for Ω, Θ, o and ω (CLRS, p. 51). e.g. log n = O(n) and n = O(n2), so log n = O(n2)
6Swap sides
f = Θ(g) ⟺ g = Θ(f), and f = O(g) ⟺ g = Ω(f)
CLRS, p. 52. e.g. n = O(n2), so n2 = Ω(n)
“=” only works one way
n = O(n2) and n2 = O(n2) do not give n = n2. Read “=” as “is in”, and never write it the other way round, as in O(n2) = n.
