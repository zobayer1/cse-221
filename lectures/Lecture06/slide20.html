Proving Big-Omega

Is 2n2 − 10n = Ω(n2)?

1We need, for all n ≥ n0:2n2 − 10n ≥ c · n2
2For a lower bound, a minus term must be paid for with part of the top term. For n ≥ 10:10n ≤ n2, so 2n2 − 10n ≥ 2n2 − n2 = n2
c = 1, n0 = 10 work, so 2n2 − 10n = Ω(n2).
For a lower bound, drop the positive terms

That makes the expression smaller: 2n2 + 3n + 5 ≥ 2n2 for every n ≥ 1, so c = 2, n0 = 1.

Not every pair works

n is not Ω(n2): n ≥ c · n2 means c · n ≤ 1, which fails once n > 1/c.
