Proving Big-O: find c and n0

Is 2n2 + 3n + 5 = O(n2)?

Method
Example
1Write down what we need, with c and n0 still unknown.
We need, for all n ≥ n0:2n2 + 3n + 5 ≤ c · n2
2For n ≥ 1, raise every term of f up to g. Each term can only grow.
For n ≥ 1:3n ≤ 3n2 and 5 ≤ 5n2
3Add up the coefficients. That sum is c, and n0 = 1.
So, for every n ≥ 1:2n2 + 3n + 5 ≤ 2n2 + 3n2 + 5n2 = 10n2
c = 10, n0 = 1 work, so 2n2 + 3n + 5 = O(n2).
