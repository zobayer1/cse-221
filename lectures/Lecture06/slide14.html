Trading c for n0
Another pair

Can c = 3 work for 2n2 + 3n + 5 ≤ c · n2?

We need 2n2 + 3n + 5 ≤ 3n2, that is n2 ≥ 3n + 5. It fails for n ≤ 4 and holds from n = 5 on: once n ≥ 5, n2 ≥ 5n = 3n + 2n ≥ 3n + 10.

So c = 3, n0 = 5 works too. Both pairs prove the same thing.

Tip: for an upper bound, drop the negative terms
Dropping a negative term makes the expression larger, so a ceiling for the larger one is a ceiling for f too. For n ≥ 1: 5n3 − 2n2 + 4 ≤ 5n3 + 4 ≤ 5n3 + 4n3 = 9n3, so c = 9, n0 = 1.
