Both knobs together (2)
Example

Does f(n) = 3n + 10 grow no faster than g(n) = n?

c = 33n + 10 ≤ 3n is never true
c = 4, n0 = 103n + 10 ≤ 4n exactly when n ≥ 10
c = 13, n0 = 13n + 10 ≤ 13n exactly when n ≥ 1

One working pair is enough: 3n + 10 grows no faster than n. This is the definition of Big-O, next.
