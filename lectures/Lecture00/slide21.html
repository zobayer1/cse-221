What is pseudocode?

Pseudocode describes an algorithm in structured, code-like steps, written for people to read, not for a computer to run.

Precise

Each step means exactly one thing, so anyone following it does the same work.

Language-free

No types, semicolons or library calls. It translates easily into C, Java or Python.

To the point

Leaves out details that don’t change the idea. Plain English is fine: “exchange A[i] with A[j]”.
