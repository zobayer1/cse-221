Course goals

Given a computational problem, by the end of this course you should be able to

1

Solve

Design a step-by-step method that turns any valid input into the right output.

2

Prove correctness

Show it works for every input, not just the cases you tested.

3

Argue efficiency

Bound how its time and memory grow as the input gets larger.

4

Communicate

Explain the idea clearly with pseudocode, proofs and analysis.
