Comparison sorting

A comparison sort puts elements in order using only one kind of question about them: is A[i] ≤ A[j]?

The problem
InputAn array A of n elements
OutputThe same elements rearranged so that A[0] ≤ A[1] ≤ … ≤ A[n − 1]
AllowedCompare two elements, and move or swap them
What we count
ComparisonsHow many times we ask A[i] > A[j]? This drives the running time.
Swaps (or shifts)How many times elements move. Matters when moving is expensive.
PassesHow many times the outer loop runs.

Today: bubble, insertion and selection sort, all comparison sorts. Later: merge sort and quicksort, and sorts that do not compare at all.
