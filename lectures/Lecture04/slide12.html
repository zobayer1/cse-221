Merge sort
John von Neumann, 1945
1MERGE-SORT(A, lo, hi)
2    if lo ≥ hi                  ◃ base case
3        return                  // size ≤ 1
4    mid = ⌊(lo + hi) / 2⌋       ◃ split
5    MERGE-SORT(A, lo, mid)      ◃ recurse
6    MERGE-SORT(A, mid + 1, hi)  ◃ recurse
7    MERGE(A, lo, mid, hi)       ◃ combine
First call
MERGE-SORT(A, 0, n − 1)

MERGE here merges A[lo..mid] and A[mid+1..hi] into a temporary array, then copies it back into A[lo..hi].
