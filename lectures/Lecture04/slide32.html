Quicksort: properties
In-place

All swaps happen inside A. Only the recursion stack: O(log n) on average.

Stable
2a2b1
→
12b2a

Final pivot swap: 1 jumps to the front, sending 2a past 2b.
The same long-swap problem as selection sort.

Pros

  • No extra array: memory friendly
  • Fast in practice: simple loops scanning memory in order
  • Random pivot: expected O(n log n) on any input

Cons

  • O(n2) worst case (rare with a random pivot)
  • Not stable
  • Many equal keys can hurt this simple PARTITION
