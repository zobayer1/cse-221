Ternary search: time complexity

Same method as binary search: track the range size and the work per step. Now each step computes m1 and m2 and makes up to 4 comparisons. Still constant work, c′.

As a recurrence: T(n) = T(n/3) + O(1). Compare binary search: T(n) = T(n/2) + O(1).

How many steps?
n / 3k ≥ 1 still something to search
n ≥ 3k
k ≤ log3 n
At most log3 n + 1 steps of c′ work:
T(n) = c′ (log3 n + 1)
= O(log3 n)
Best: O(1)x is at m1 or m2 in the first step.
Worst: O(log n)x is absent, or found in the last step.
