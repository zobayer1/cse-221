Linear search, recursively
1LINEAR-SEARCH-REC(A, n, x, i)
2    if i == n
3        return NIL
4    if A[i] == x
5        return i
6    return LINEAR-SEARCH-REC(A, n, x, i + 1)

Start with LINEAR-SEARCH-REC(A, n, x, 0). Each call checks one element, then hands the rest of the array to the next call.

Trace: find 42 in [17, 3, 42, 8]
i = 0 A[0] = 17 ≠ 42, call with i = 1
i = 1 A[1] = 3 ≠ 42, call with i = 2
i = 2 A[2] = 42, return 2
2 is passed back up to the first call

Time

O(n)

One element per call, up to n calls.
T(n) = T(n − 1) + c

Extra space

O(n)

Up to n calls waiting on the call stack.
The loop version needs only O(1).
