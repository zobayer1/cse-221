Ternary search, recursively
1TERNARY-SEARCH-REC(A, x, lo, hi)
2    if lo > hi
3        return NIL
4    third = ⌊(hi − lo) / 3⌋
5    m1 = lo + third
6    m2 = hi − third
7    if A[m1] == x
8        return m1
9    if A[m2] == x
10        return m2
11    if x < A[m1]
12        return TERNARY-SEARCH-REC(A, x, lo, m1 − 1)
13    elseif x > A[m2]
14        return TERNARY-SEARCH-REC(A, x, m2 + 1, hi)
15    else
16        return TERNARY-SEARCH-REC(A, x, m1 + 1, m2 − 1)

Start with TERNARY-SEARCH-REC(A, x, 0, n − 1). Each call checks m1 and m2, then searches one third.

Trace: find 42
(lo 0, hi 7) m1 2, m2 542 > 31, search (6, 7)
(lo 6, hi 7) m1 6, m2 7A[m1] = 42, return 6
6 is passed back up to the first call

Time

O(log n)

One call on a third of the range: T(n) = T(n/3) + c′

Extra space

O(log n)

Up to log3 n + 1 calls on the stack. The loop version needs only O(1).
