binary_search

Is x there? Returns only true or false.

lower_bound

Position of the first element ≥ x: the first copy, or where x would be inserted.

upper_bound

Position of the first element > x: one past the last copy.

vector<int> a = {3, 8, 17, 17, 17, 31, 42};

binary_search(a.begin(), a.end(), 17)  // true
lower_bound(a.begin(), a.end(), 17) - a.begin()  // 2
upper_bound(a.begin(), a.end(), 17) - a.begin()  // 5
// count of 17 = 5 − 2 = 3

lower_bound(a.begin(), a.end(), 20) - a.begin()  // 5
// 20 is absent: 5 is where it would go

Our binary search returns some matching index, which is not enough when there are copies. All three are O(log n) and need a sorted range. lower_bound and upper_bound return iterators, so subtract a.begin() to get an index.
