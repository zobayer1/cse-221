Using the simulators
1

Download the HTML file

One file for each algorithm:

linear_search_simulator.htmlbinary_search_simulator.htmlternary_search_simulator.html
2

Open it in your browser

Double-click it, or drag it into Chrome, Firefox or Edge. No installation and no internet needed.

3

Step through it

Pick a target, then use → and ←, or Space to play. Try every preset.
