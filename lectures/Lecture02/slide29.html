Can binary search find a peak? (2)

Both find a peak. What differs is the information they use.

Binary search

Uses a monotonic decision: a yes/no test that flips once.

Ternary search

Uses unimodality, by comparing function values f(m1) and f(m2).

It is not that one can optimize and the other cannot. They use different information to throw away part of the range.

For continuous functions, ternary search shines when you can compute f(x) but not its derivative. It needs about O(log((R − L)/ε)) steps for precision ε on [L, R].
