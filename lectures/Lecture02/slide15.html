Binary search, recursively
1BINARY-SEARCH-REC(A, x, lo, hi)
2    if lo > hi
3        return NIL
4    mid = lo + ⌊(hi − lo) / 2⌋
5    if A[mid] == x
6        return mid
7    elseif A[mid] < x
8        return BINARY-SEARCH-REC(A, x, mid + 1, hi)
9    else
10        return BINARY-SEARCH-REC(A, x, lo, mid − 1)

Start with BINARY-SEARCH-REC(A, x, 0, n − 1). Each call checks the middle, then searches one half.

Trace: find 42
(lo 0, hi 7) mid 317 < 42, search (4, 7)
(lo 4, hi 7) mid 531 < 42, search (6, 7)
(lo 6, hi 7) mid 642 found, return 6
6 is passed back up to the first call

Time

O(log n)

Constant work, then one call on half the range.
T(n) = T(n/2) + c

Extra space

O(log n)

Up to log2 n + 1 calls on the call stack.
The loop version needs only O(1).
