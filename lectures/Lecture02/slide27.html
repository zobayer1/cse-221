Example: closest point on a segment

Find the point on segment AB closest to P. Walk along it as Q(t) = A + t(B − A) for t from 0 to 1. The distance d(t) = |Q(t) − P| falls, then rises: it is unimodal.

Check: projecting P onto AB gives the exact answer, t = 0.45 and Q = (4.6, 2.8). Ternary search finds it without needing that formula.

1CLOSEST-POINT(A, B, P)
2    lo = 0
3    hi = 1
4    for t = 1 to 100
5        m1 = lo + (hi − lo) / 3
6        m2 = hi − (hi − lo) / 3
7        if d(m1) < d(m2)
8            hi = m2
9        else
10            lo = m1
11    return Q((lo + hi) / 2)
  • First step: d(1/3) ≈ 3.73 < d(2/3) ≈ 4.07, so the minimum is not in (2/3, 1]. Drop that third.
  • Here we drop one third and keep two, so the range shrinks to 2/3 each step. After 100 steps it is about 10−18 wide.
  • Real numbers, so no exact match: stop after a fixed number of steps, or when hi − lo is tiny.
