3 comparisons instead of 7.

  • lo ≤ hiThe range is not empty yet. When lo > hi, x is not in A.
  • mid ± 1A[mid] is already checked, so leave it out. Using mid instead can loop forever.
  • lo + ⌊…/2⌋Same as ⌊(lo + hi)/2⌋, but lo + hi can overflow in real code.
