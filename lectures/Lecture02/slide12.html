Sorted is not the real requirement

Binary search needs a monotonic order: as x grows, f(x) only goes up (or only goes down). A sorted array is one example, with f(i) = A[i].

Monotonic: it works

f(mid) < y, so every x left of mid has f(x) < y too. Safe to drop.

Not monotonic: it fails

f(mid) > y, so we drop the right side. But the only answer was there.
