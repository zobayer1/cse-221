Binary search: summary
Cost
Best casex is the first middleO(1)
Average caseO(log n)
Worst casex absent, or found lastO(log n)
Extra spaceloop / recursionO(1) / O(log n)
  • Needs a monotonic order (a sorted array is the usual case)
  • Needs O(1) access to any position (an array, not a linked list)
Watch out for
  • Missing elementThe loop must end when lo > hi, then return NIL.
  • DuplicatesReturns some matching index. For the first one, keep searching left.
  • Off-by-oneUse lo ≤ hi and mid ± 1. One slip loses an element or loops forever.
  • Unsorted inputNo error, just a silently wrong answer.
