Ternary search: summary
Cost on a sorted array
Best casex at m1 or m2O(1)
Worst casex absent, or found lastO(log n)
Extra spaceloop / recursionO(1) / O(log n)
Two uses
  • Sorted arrayKeeps 1/3, about log3 n steps. More comparisons than binary search, so binary is preferred.
  • Unimodal peakKeeps 2/3, about log((R − L)/ε) steps. Useful when only f(x) can be computed.
Watch out for
  • Not unimodalSeveral local peaks: it may return the wrong one.
  • Flat stretchesIf f(m1) = f(m2) on a plateau, the peak can be lost. Needs strict rise and fall.
  • Real numbersStop after a fixed number of steps, not on an exact hi − lo test.
  • Middle caseIn the array version, move both ends: lo = m1 + 1 and hi = m2 − 1.
