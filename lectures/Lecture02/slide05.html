Linear search
1LINEAR-SEARCH(A, n, x)
2    for i = 0 to n − 1
3        if A[i] == x
4            return i
5    return NIL

O(1)

Best case

x is the first element: 1 comparison.

O(n)

Worst case

x is the last element, or not in A at all: n comparisons.

O(·) is an upper bound for large n, as in Lecture 1. The formal definition comes later in the course.
