Linear search: summary
Comparisons
Best casex is firstO(1)
Average caseabout n/2O(n)
Worst casex is last, or absentO(n)

Works on unsorted data. It needs no preparation at all.

Does a sorted array make it faster?

Not by much. On sorted data, linear search can stop early once A[i] > x, so a missing target is detected sooner.

But it still moves one element at a time. If x is the largest element, it still makes n comparisons: O(n).

To get faster, the algorithm must change: use the order to skip elements. That is binary search.
