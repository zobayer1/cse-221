Algorithms are not programs

An algorithm is the idea behind a solution, not the complete code. It can be written as an informal, high-level description in pseudocode, or drawn as a flowchart.

Pseudocodethis course

Structured, code-like steps without the syntax of any real language.

m = A[0]
for i = 1 to n − 1
    if A[i] < m
        m = A[i]
return m

Flowchart

The same steps drawn as a diagram, with standard shapes joined by arrows.

Program

A full implementation in a real language, with exact types, syntax and 0-based indexing.

int findMin(int a[], int n) {
  int m = a[0];
  for (int i = 1; i < n; i++)
    if (a[i] < m)
      m = a[i];
  return m;
}
