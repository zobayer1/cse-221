The maximum-subarray problem
Definition
Input: an array A[0..n − 1] of numbers, some of them negative.
Output: indices i ≤ j that make A[i] + A[i + 1] + … + A[j] as large as possible.

Contiguous

No skipping: adding up only the profitable days is not allowed.

Nonempty

If every number is negative, the answer is the largest single number.

No negatives?

Then the whole array wins. The negatives make it a real problem.
