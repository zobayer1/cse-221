MAX-SUBARRAY-SCAN: Θ(n)
1MAX-SUBARRAY-SCAN(A, n)
2    best = −∞
3    sum = 0
4    start = 0
5    for j = 0 to n − 1
6        sum = sum + A[j]          // sum of A[start..j]
7        if sum > best
8            best = sum
9            best-i = start
10            best-j = j
11        if sum < 0              // a negative stretch never helps
12            sum = 0
13            start = j + 1
14    return (best-i, best-j, best)
How it works
Lines 6–10Extend the current stretch by A[j] and keep the best sum seen.
Lines 11–13A negative sum is dropped: the next stretch starts at j + 1.
OrderLine 7 runs before line 11, so an all-negative array still returns its largest element.
CostOne pass, Θ(1) per element: Θ(n). For n = 105, that is 105 additions.
