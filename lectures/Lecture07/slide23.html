FIND-MAXIMUM-SUBARRAY: the three steps

Base caselines 2–3

One element is its own best subarray: return it.

Divideline 4

Split at the middle: Θ(1).

Conquerlines 5–6

Solve both halves recursively: 2T(n/2).

Combinelines 7–13

Find the best crossing subarray in Θ(n), then return the best of the three.

First call: FIND-MAXIMUM-SUBARRAY(A, 0, n − 1)
