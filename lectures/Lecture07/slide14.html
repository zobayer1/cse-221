Brute force: how many steps?
Count line 7

A subarray of length L costs L additions, and there are n − L + 1 of them.

1 · n + 2 · (n − 1) + … + n · 1
= n(n + 1)(n + 2) / 6 = Θ(n3)

For n = 8: 8 + 14 + 18 + 20 + 20 + 18 + 14 + 8 = 120 additions.
