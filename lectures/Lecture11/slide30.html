The step did not close

The guess was T(n) ≤ cn, with one fixed c. The step ended with

cn + n > cn

which is more than cn. Writing “= O(n)” hid the failure.

The constant keeps growing
SizeBound on T
1c · 1
2(c + 1) · 2
4(c + 2) · 4
⋮⋮
n(c + log n) · n

Each doubling adds 1 to the “constant”. After log n doublings it is c + log n, which is not a constant: the bound is really cn + n log n.

The rule
End the inductive step with exactly the guessed form, T(n) ≤ cn, with the same c. Never switch to O( ) in the middle of an induction. (CLRS p. 86, “Avoiding pitfalls”)
