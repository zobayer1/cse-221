T(n)= T(n/2) + c = T(n/4) + c + crule for T(n/2) = T(n/8) + 3c = T(n/2k) + kcafter k steps Base case: n/2k = 1, so k = log n  (see the box) T(n)= T(1) + c log n = c(log n + 1) = Θ(log n)

Four halvings take 16 down to 1, and log2 16 = 4.

In general n/2k = 1 when 2k = n, that is, k = log2 n. For n = 109 that is only about 30.

The same recurrence as binary search (Lecture 2). Here n is a power of 2, so every n/2k is a whole number;
