The master theorem: three cases

Slide 17’s three kinds of sums, with r = a/bk and L = logb n:

Leaves win: a > bk

The last level wins

Last level: cnk · rL = cnk · aL / nk

= c · aL = c · nlogb a (bL = n; slide 16)

T(n) = Θ(nlogb a)

A tie: a = bk

Every level counts

L + 1 levels, each cnk:

cnk(logb n + 1)

T(n) = Θ(nk log n)

Root wins: a < bk

The first level wins

cnk ≤ T(n) < cnk · 1/(1 − r)

and 1/(1 − r) is a constant

T(n) = Θ(nk)
