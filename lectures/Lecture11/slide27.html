The master theorem: one ratio

Take the work outside the calls to be a power of n:T(n) = aT(n/b) + cnk

Level i of the recursion tree
Callsai, each of size n/bi
One call costsc(n/bi)k = cnk(bk)i
The level costsai · cnk(bk)i = cnk · (a/bk)i

Each level is r = a/bk times the one above:

T(n) = cnk(1 + r + r2 + ⋯ + rL), L = logb n

Check against the trees
2T(n/2) + cnr = 2/2 = 1every level
2T(n/2) + cn2r = 2/4 = ½the root
4T(n/2) + cnr = 4/2 = 2the leaves
2T(n/2) + cr = 2/1 = 2the leaves

A constant c is cn0, so k = 0 and bk = 1.
