Application: finding a cycle
The homework graph at time 4.

Why care? To install a package, first install the packages it needs.

Here no install order works: the dependencies form a cycle.

The idea
A back edge (u, v) leads to an ancestor v of u. The tree path from v down to u, plus (u, v), is a cycle.

At time 4, d scans b and finds it gray: (d, b) is a back edge. Cycle: b → c → d → b.
