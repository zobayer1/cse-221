Example 2: merge sort, the inductive step

MERGE-SORT, with n a power of 2:T(n) = 2T(n/2) + n, T(1) = 1

Guess, from the recursion tree:T(n) ≤ cn log n

Inductive step

Assume the guess for size n/2: T(n/2) ≤ c(n/2) log(n/2).

T(n)= 2T(n/2) + n ≤ 2 · c(n/2) log(n/2) + nsubstitute the guess = cn(log n − 1) + nlog(n/2) = log n − 1 = cn log n − cn + n ≤ cn log nif c ≥ 1, since then −cn + n ≤ 0
The goal

End with exactly the guessed form, cn log n, with the same c.

Why minus 1?

log(n/2) = log n − log 2, and log 2 = 1 in base 2.
