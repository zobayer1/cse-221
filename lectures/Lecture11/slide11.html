Iteration method: doubling at every step

HANOI:T(n) = 2T(n − 1) + c, T(0) = c

Unroll it
T(n)= 2T(n − 1) + c = 2[2T(n − 2) + c] + c = 4T(n − 2) + 2c + c = 8T(n − 3) + 4c + 2c + c = 2kT(n − k) + c(2k−1 + ⋯ + 2 + 1)after k steps = 2kT(n − k) + c(2k − 1)see the box Base case: n − k = 0, so k = n T(n)= 2nc + c(2n − 1) = c(2n+1 − 1) = Θ(2n)
Why is it 2k − 1?

1 + 2 + 4 + 8 in binary:

00011 00102 01004 +10008 111115 +11000016

Four ones, plus 1, carry all the way: 24. So 1 + 2 + ⋯ + 2k−1 = 2k − 1.

Trivia64 disks take 264 − 1 moves. At one move per second, that is about 585 billion years.
