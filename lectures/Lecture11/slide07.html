DFS: pseudocode
1DFS(G)
2    for each vertex u ∈ G.V
3        u.color = WHITE
4        u.π = NIL
5    time = 0
6    for each vertex u ∈ G.V
7        if u.color == WHITE
8            DFS-VISIT(G, u)

Paint every vertex white, then start a new search from each vertex that is still white.

1DFS-VISIT(G, u)
2    time = time + 1     // u is discovered
3    u.d = time
4    u.color = GRAY
5    for each v ∈ G.Adj[u]  // explore (u, v)
6        if v.color == WHITE
7            v.π = u
8            DFS-VISIT(G, v)
9    u.color = BLACK     // u is finished
10    time = time + 1
11    u.f = time

Discover u, go deeper into each white neighbor, then finish u. Returning from line 8 is the backtrack.
