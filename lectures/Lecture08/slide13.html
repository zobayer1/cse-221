Answer: four halves is no faster

Count the leaves: n = 16

Each level has 4 times as many calls.
log2 n levels down, there are
4log2 n = (2log2 n)2 = n2 one-digit products.

For n = 16: 44 = 256 = 162. The shifts and sums above the leaves do not change that: the total is still Θ(n2).

No gain
Splitting alone does not help: four half-size products cost as much as one full-size product. We need to multiply fewer halves.
