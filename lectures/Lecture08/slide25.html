RANGE-MIN: the three steps

Base caselines 2–3

A part with one element, lo == hi: the query is that element, so return A[lo].

Divideline 4

Split the part A[lo..hi] at mid = ⌊(lo + hi) / 2⌋. If the query crosses mid, cut it into A[i..mid] and A[mid + 1..j].

Conquerlines 5–11

Answer each piece inside its own half, recursively. Cases 1 and 2 have one piece; case 3 has two.

Combineline 12

Case 3: return the smaller of the two answers, Θ(1). Cases 1 and 2: return the one answer as it is.

First call: RANGE-MIN(A, 0, n − 1, i, j)
