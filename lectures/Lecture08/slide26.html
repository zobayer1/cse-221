Example: RMQ(1, 5)
Count the calls

Each box is one call of RANGE-MIN on the part A[lo..hi]; the band inside is its query A[i..j], with the answer.

11 calls for a range of 5 elements. Each element of A[1..5] ends in a base case of its own , so one query still costs Θ(j − i + 1), like RMQ-SCAN.

Nothing is kept
