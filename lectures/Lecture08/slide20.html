Range minimum query (RMQ)

Given an array and a range of positions, find the smallest value in that range.

RMQ(1, 5) = min(8, 3, 9, 6, 2) = 2

Input

An array A[0..n − 1] and a range i, j with 0 ≤ i ≤ j ≤ n − 1. The range includes both ends.

Output

RMQ(i, j) = min(A[i], A[i + 1], …, A[j]), the smallest value in A[i..j].
