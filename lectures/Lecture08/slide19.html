In practice: a bigger base case

Base case on the slides

1KARATSUBA(x, y, n)
2    if n == 1
3        return x · y     // one-digit product

Base case in practice

1KARATSUBA(x, y, n)
2    if n ≤ 9
3        return x · y     // one hardware multiply

Two 9-digit numbers multiply to less than 1018, which fits a 64-bit word: the hardware does it in one step.

Each level has 3 times as many calls as the one above, so skipping the last 3 levels makes about 27 times fewer calls.

Still Θ(n1.585): only the constant shrinks.
