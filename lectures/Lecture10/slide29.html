Finding a cycle: pseudocode
1HAS-CYCLE(G)
2    for each vertex u ∈ G.V
3        u.color = WHITE
4    for each vertex u ∈ G.V
5        if u.color == WHITE
6            if CYCLE-VISIT(G, u)
7                return TRUE
8    return FALSE

Same outer loop as DFS: try every vertex that is still white.

1CYCLE-VISIT(G, u)
2    u.color = GRAY
3    for each v ∈ G.Adj[u]
4        if v.color == GRAY   // back edge
5            return TRUE
6        elseif v.color == WHITE
7            if CYCLE-VISIT(G, v)
8                return TRUE
9    u.color = BLACK
10    return FALSE

DFS-VISIT without the times, plus one test (lines 4–5): stop at the first gray neighbor.

Time: O(V + E), the same as DFS. It can stop early, as soon as it finds a back edge.
