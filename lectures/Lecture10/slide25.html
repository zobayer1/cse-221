Bicolorable graphs
Definition
An undirected graph is bicolorable if each vertex can get one of two colors so that every edge joins two different colors.

Bipartite if and only if bicolorable.

  • Bipartite ⇒ bicolorable: color one set blue and the other orange. Every edge goes between the sets, so its ends get different colors.
  • Bicolorable ⇒ bipartite: the blue vertices form one set and the orange ones the other. Every edge joins two colors, so it goes between the sets.

Two colors: even d, odd d

Every edge goes between the two rows.
