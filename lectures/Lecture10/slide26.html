Bipartite test: pseudocode
1BIPARTITE(G, s)
2    for each vertex u ∈ G.V − {s}
3        u.color = WHITE
4        u.d = ∞
5    s.color = GRAY
6    s.d = 0
7    Q = ∅
8    ENQUEUE(Q, s)
9    while Q ≠ ∅
10        u = DEQUEUE(Q)
11        for each v ∈ G.Adj[u]
12            if v.color == WHITE
13                v.color = GRAY
14                v.d = u.d + 1
15                ENQUEUE(Q, v)
16            elseif v.d == u.d   // same layer
17                return FALSE
18        u.color = BLACK
19    return TRUE
  • Lines 16–17: v is already discovered, in u’s layer. Edge (u, v) stays inside one layer: not bipartite.
  • Line 19: no edge stays inside a layer, so even d and odd d bicolor the graph: bipartite.
  • The two colors are even and odd d, not WHITE, GRAY and BLACK.
  • Time: O(V + E), as BFS. Test each component.
