Arrow u → v: v needs u, so install u first.

Now the dependencies have no cycle. In what order do we install the packages?

Topological sort
An order of all the vertices such that for every edge (u, v), u comes before v.

It exists only when G has no cycle: G must be a DAG (Directed Acyclic Graph).
