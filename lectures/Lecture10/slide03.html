The graph traversal problem
Definition
Graph traversal, or graph search, means systematically following edges to visit vertices.
Input

A graph G = (V, E), directed or undirected, and a source vertex s ∈ V

→
Output

Every vertex reachable from s:

{ v ∈ V : there is a path from s to v }
One instance, with s = 0
→
Correct output: {0, 1, 2, 3, 4}
How to reach them is up to the algorithm.
