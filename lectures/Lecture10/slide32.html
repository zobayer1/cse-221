Topological sort with DFS
1TOPOLOGICAL-SORT(G)
2    call DFS(G) to compute finishing times v.f for each vertex v
3    as each vertex is finished, insert it onto the front of a linked list
4    return the linked list of vertices
  • Line 3 is one extra step in DFS-VISIT, right after u.f = time: put u at the front of the list.
  • So the list holds the vertices in decreasing order of f: the last vertex to finish comes first.
  • Why? A vertex finishes only after everything it leads to has finished, so everything that must come after it is already in the list.
  • Time: Θ(V + E), for DFS plus an O(1) insertion per vertex.
