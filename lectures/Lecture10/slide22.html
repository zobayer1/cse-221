Connected components
Definition
A connected component of an undirected graph is a set of vertices that are all reachable from each other, with no other vertex reachable from them.
3 components: {A, B, C}, {D, E}, {F}
  1. Pick any white vertex and run BFS from it. The vertices it discovers are one component.
  2. Repeat until no vertex is white.
  3. Initialize the vertices once, not on every run, so the total time stays O(V + E).
