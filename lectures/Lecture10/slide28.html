Try n = 1. T(1) = 1, but c · 1 · log 1 = 0, and 1 ≤ 0 is false. It fails.

2

Big-O only needs large n (Lecture 6). Start at n0 = 2:
T(2) = 2T(1) + 2 = 4 ≤ c · 2 · log 2 = 2c, so c ≥ 2.

3

The step covers the rest. For n ≥ 4 it uses size n/2 ≥ 2, which is already proved.

4

Pick c = 2 (≥ 1 for the step, ≥ 2 for the base): T(n) ≤ 2n log n for all n ≥ 2, so T(n) = O(n log n).
