Unrolling a recurrence

FACTORIAL:T(n) = T(n − 1) + c, T(1) = c

Unroll it
T(n)= T(n − 1) + c = T(n − 2) + c + cuse the rule again on T(n − 1) = T(n − 3) + 3c = T(n − k) + kcafter k steps Base case: n − k = 1, so k = n − 1 T(n)= T(1) + (n − 1)c = cn = Θ(n)
The recipe
1Expand: replace T(n − 1) using the same rule.
2Spot the pattern after k steps.
3Pick k so that the size reaches the base case.
4Add up what is left.

Also called the iteration method or back-substitution.
