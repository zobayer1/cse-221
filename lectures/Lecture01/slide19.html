The RAM model (1)

The random-access machine: the imaginary computer we analyze algorithms on.

1

One processor

Instructions run one after another, never at the same time.

2

Every instruction costs one step

Each basic instruction takes the same constant time.

3

Every memory access costs one step

Reading or writing a variable takes constant time, even indexing an array.

4

Simple data, limited words

Integers, floating-point numbers and characters. Each word holds a limited number of bits, enough to store n.
