Why exact complexity is hard to calculate

Finding the exact running time is hard

  • Exact counts get messyEvery operation, every line, every constant.
  • Best case depends on the inputIt is often a lucky special case, and tells us little.
  • Average case is difficult to computeWe need to know how likely each input is.
→

So we usually focus on the worst case

  • Easier to computeFind the input that makes the algorithm work hardest.
  • Usually close to the actual running timeFor many algorithms, bad inputs are common.
  • It is a guaranteeThe algorithm never takes longer than this, on any input.
