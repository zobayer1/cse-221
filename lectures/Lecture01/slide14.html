Best, worst and average case (1)

The same algorithm can take a different number of steps on different inputs of the same size.

Worst case

The maximum number of steps taken on any input of size n.

MIN exampleDecreasing array: every element is a new minimum
T(n) = 3n − 1

Best case

The minimum number of steps taken on any input of size n.

MIN exampleA[0] is already the minimum: the line m = A[i] never runs
T(n) = 2n

Average case

The average number of steps over all inputs of size n, usually assuming each is equally likely.

MIN exampleSomewhere in between, depending on how the inputs are spread
2n ≤ T(n) ≤ 3n − 1
