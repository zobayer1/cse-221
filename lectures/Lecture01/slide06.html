Memory (space)

Space is the amount of memory an algorithm uses, counted in memory cells, as a function of input size n.

Input space

Memory that holds the input itself. It is needed no matter which algorithm we use.

Extra space

Memory the algorithm needs beyond the input: variables, copies, stacks. This is what we usually compare.

Fixed extra space
SUM(n) needs only total and i: 2 cells, whatever n is.
Growing extra space
Copying A[0..n − 1] into a new array B needs n cells.
