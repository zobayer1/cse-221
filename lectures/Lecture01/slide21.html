Using the RAM model fairly
Don't abuse it

No magic instructions

A “sort” instruction would make sorting one step. Real computers don't have one, so the RAM model doesn't either.

Watch the grey areas

Computing xn is not one step in general. Shortcuts like 2k by a bit shift only count when the result fits in a word.

Words can't grow

Otherwise we could pack huge amounts of data into one word and process it in one step.

What it leaves out, and why that's fine

No memory hierarchy

Caches and virtual memory are ignored. Models that include them are much harder to work with.

Still a good predictor

In practice, RAM-model analysis predicts real performance well.
