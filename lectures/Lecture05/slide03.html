Can we sort faster?Think
Last class

Any comparison sort needs Ω(n log n) comparisons in the worst case.

Its decision tree needs n! leaves, so it is at least log(n!) tall.

So, can we ever sort in O(n) time?

1The only question the tree asks is “is A[i] ≤ A[j]?”. Must every algorithm work that way?
2What else could we learn about an element, just by looking at it?
