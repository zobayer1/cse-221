Rule
Add up how many times each line runs. Nesting multiplies the work only by how many times the outer loop runs. A loop that runs a fixed number of times is just a constant factor.
Caution
That holds only while d is fixed. If the keys can grow up to n, they need about log10 n digits, and decimal radix sort is Θ(n log n) again.
