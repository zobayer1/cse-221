Counting sort
1COUNTING-SORT(A, B, n, k)
2    let C[0..k] be a new array
3    for i = 0 to k                 ◃ clear
4        C[i] = 0
5    for j = 0 to n − 1             ◃ count
6        C[A[j]] = C[A[j]] + 1
7    // C[i] is now the number of keys equal to i
8    for i = 1 to k                 ◃ add up
9        C[i] = C[i] + C[i − 1]
10    // C[i] is now the number of keys ≤ i
11    for j = n − 1 downto 0         ◃ place
12        C[A[j]] = C[A[j]] − 1
13        B[C[A[j]]] = A[j]
Input

A[0..n − 1], each key an integer from 0 to k

Output

B[0..n − 1], the same keys in sorted order

Why step down first?

Slots are 0-indexed: the keys ≤ v fill slots 0 to C[v] − 1, so line 12 moves C[v] to a free slot before line 13 uses it.
