Graph representation: adjacency list
Definition
Number the vertices 0, 1, …, n − 1. The adjacency list representation of G = (V, E) is an array Adj of n lists, with:
Adj[u] = { v : (u, v) ∈ E }
Edge (1, 3) puts 3 in Adj[1] and 1 in Adj[3].

Unweighted graph: a list holds the neighbors. Weighted graph: each entry also holds the edge’s weight.
