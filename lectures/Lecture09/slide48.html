Is the graph bipartite?
Definition
An undirected graph is bipartite if its vertices split into two sets, and every edge goes between them.

Run BFS. The graph is bipartite if and only if no edge joins two vertices with the same d.

Bipartite

No edge stays inside one layer.

Not bipartite

(t, x) and (u, y) join equal d.

The two sets: even d and odd d. In a disconnected graph, test each component.
